# SimpleTrade — Landing Page & UI Prototype

A visual, no-code algorithmic strategy development platform designed to democratize automated execution for retail traders. 

*Selected for application to the TMU DMZ Basecamp Startup Incubator.*

---

## Overview
Retail traders often understand market structure and technical indicators but lack the complex Python or C++ engineering skills required to build reliable, high-frequency execution algorithms.

SimpleTrade provides a drag-and-drop canvas where users can visually map out trading logic. This repository contains the foundational frontend code (HTML/CSS/JS) and UI/UX assets used for the initial landing page and incubator pitch.

---

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Prototyping & Assets:** Google Stitch, Figma
* **Architecture Concept:** Visual node-based logic builder (frontend) converting to a Python-based API execution engine (backend).

---

## Project Structure
* `index.html` - Core landing page structure and pitch framework.
* `style.css` - Custom styling and responsive layouts.
* `script.js` - Interactive DOM elements and frontend logic.
* UI Assets (`logo.png`, team photos)
